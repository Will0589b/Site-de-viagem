# ExploreMundo

Landing page responsiva de uma agência de viagens fictícia, criada para apresentar diferentes estilos de destinos em uma interface simples e agradável.

## Demonstração online

[Acessar o ExploreMundo](https://will0589b.github.io/exploremundo/)

## Funcionalidades

- Página inicial com apresentação do projeto
- Seção de destinos populares
- Página adicional com mais opções de viagem
- Navegação por links internos
- Layout responsivo para computadores e dispositivos móveis
- Acesso direto ao perfil profissional do autor

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Design responsivo

## Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno.

Não é necessário instalar dependências.
